## Briefing Veille Sécurité - 20 Novembre 2026

1. **Vulnérabilité critique dans une passerelle VPN** — Exploitation observée en conditions réelles depuis 72 h. Enjeu : prioriser la mise à jour des systèmes et vérifier les indicateurs de compromission.

2. **Campagne de rançongiciel ciblant les sauvegardes non segmentées** — Vecteur initial : services de sauvegarde exposés sur Internet. Enjeu : segmenter les sauvegardes et renforcer la sécurité des points de sauvegarde.

3. **Correctif hors cycle pour un hyperviseur** — Redémarrage requis pour fermer une élévation de privilèges locale. Enjeu : planifier une fenêtre de maintenance pour les hôtes non redémarrés.

4. **Fin de support pour une gamme de pare-feu** — Pas de correctifs à partir de mars 2027. Enjeu : inventorier les parcs concernés et planifier une migration ou une remplacement.

5. **Durcissement des valeurs par défaut dans un agent de télémétrie** — Exige une authentification pour l'exposition réseau. Enjeu : migrer les configurations existantes pour éviter les risques de fuite de données.
